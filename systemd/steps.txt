1. Prepare your Node.js application
Example application directory:
/var/www/my-node-app/
├── package.json
├── package-lock.json
└── server.js

Install dependencies:
cd /var/www/my-node-app
npm install

Test that the application runs:
node server.js

Stop it with Ctrl+C after testing.
2. Find the Node.js executable path
Run:
which node
which npm

Example output:
/usr/bin/node
/usr/bin/npm

If Node.js was installed using NVM, the path might instead be under /home/youruser/.nvm/versions/node/.... Systemd does not automatically load your interactive shell's NVM environment, so you'll need to account for that.
3. Create the systemd service file
Create a new service:
sudo nano /etc/systemd/system/my-node-app.service

Add the following configuration:

[Unit]
Description=My Node.js Application
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/var/www/my-node-app
ExecStart=/usr/bin/node /var/www/my-node-app/server.js
Restart=always
RestartSec=5
Environment=NODE_ENV=production
Environment=PORT=3000

[Install]
WantedBy=multi-user.target

Adjust these values to match your environment:
- User=www-data — Linux user that runs the app. Choose a user with the required permissions.
- WorkingDirectory — absolute path to your application.
- ExecStart — absolute Node.js path and your application's entry point.
- PORT=3000 — change this to your app's port if needed.
Tip: For production, use a dedicated application user if possible, rather than running Node.js as root.

4. Reload systemd
Tell systemd to read the new service file:
sudo systemctl daemon-reload

5. Enable and start the service
Start the application immediately:
sudo systemctl start my-node-app

Enable automatic startup when the server boots:
sudo systemctl enable my-node-app

Or do both in one command:
sudo systemctl enable --now my-node-app

6. Verify the service status
Check whether the service is running:
sudo systemctl status my-node-app
